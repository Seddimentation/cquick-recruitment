# Week 2 学习总结

这周主要练习了 ROS 2 的自定义消息、话题通信和 turtlesim 控制，也整理了串口和总线舵机的学习笔记。

## ROS 2 消息与话题通信

我在 `ball_interfaces` 包里定义了 `BallPos` 消息，用来记录目标点的编号和坐标。发布节点会通过 `ball_pos` 话题发送三个目标点，订阅节点收到消息后，会在终端里显示对应的编号和坐标。

通过这次练习，我对 ROS 2 中消息、话题、发布者和订阅者之间的关系更熟悉了。

## 控制海龟依次前往三个目标点

控制节点会接收目标点和海龟当前的位置，再根据这些信息计算下一步的速度指令。三个目标点分别是：

1. `(2.0, 3.0)`
2. `(5.5, 8.0)`
3. `(9.0, 4.0)`

控制程序每隔 0.1 秒运行一次。如果海龟的朝向和目标方向差得比较多，程序会先让它转向；方向合适后再向前移动。到达目标点附近（距离小于等于 0.5）后，海龟会停下来，然后继续前往下一个点。完成三个目标后，程序会统计每个点的距离误差。

这部分让我练习了如何把订阅到的数据用于实际控制，也让我更清楚定时器回调在程序中的作用。
